# ♠ 텍사스 홀덤 — 싱글 플레이

AI 상대와 혼자서 즐기는 노리밋 텍사스 홀덤입니다.
빌드 도구나 설치 과정 없이, 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html` 을 브라우저로 열면 끝입니다.

```bash
# 그냥 열기
open index.html          # macOS
xdg-open index.html      # Linux

# 또는 로컬 서버로
python3 -m http.server 8000   # http://localhost:8000
```

## 기능

- **노리밋 홀덤 정식 룰** — 딜러 버튼 로테이션, SB/BB, 프리플랍 BB 옵션,
  최소 레이즈 규칙, 헤즈업 포지션 예외 처리
- **사이드 팟** — 스택이 서로 다른 여러 명이 올인해도 팟이 정확히 분리됩니다.
  동점 시 분할하고, 남는 칩은 버튼 다음 자리부터 배분
- **AI 상대 1~5명** — 성향이 각각 다릅니다 (타이트 / 밸런스 / 어그레시브 /
  콜링스테이션 / 트래퍼)
- **승률 표시** — 내 핸드의 예상 승률을 몬테카를로 시뮬레이션으로 계산해 보여줍니다
- **토너먼트 모드** — 칩을 잃은 플레이어는 테이블을 떠나고,
  원하면 블라인드가 일정 핸드마다 2배로 오릅니다
- 핸드 기록 패널, 효과음, 모바일 대응, 키보드 단축키

### 단축키

| 키 | 동작 |
|---|---|
| `F` | 폴드 |
| `C` | 체크 / 콜 |
| `R` | 레이즈 (슬라이더 금액으로) |
| `Space` | 다음 핸드 |

## AI 는 어떻게 판단하나요

봇은 매 결정마다 **몬테카를로 시뮬레이션**을 돌립니다.
남은 덱에서 상대 홀카드와 미래의 커뮤니티 카드를 수백 번 무작위로 뽑아
자기 패가 이기는 비율(에쿼티)을 추정합니다.

그 다음 **팟 오즈**와 비교합니다. 콜 비용이 팟 대비 싸면 낮은 승률에도 콜하고,
비싸면 접습니다. 여기에 성향 값(공격성 · 블러프 빈도 · 루즈함)과 약간의 무작위성을
더해, 같은 상황에서도 봇마다 다르게 행동하고 읽히지 않도록 했습니다.

## 구조

```
index.html         화면 구성
css/style.css      스타일
js/cards.js        카드 · 덱 · 셔플
js/evaluator.js    핸드 평가기 (5~7장 중 최고의 5장)
js/engine.js       게임 엔진 (베팅 라운드, 사이드 팟, 쇼다운)
js/ai.js           AI 판단 (에쿼티 추정 + 팟 오즈 + 성향)
js/ui.js           렌더링 & 게임 루프
test/run-tests.js  테스트
```

엔진은 UI와 완전히 분리되어 있고, `phase` 값 하나로 다음 단계를 알려줍니다.

| phase | 의미 |
|---|---|
| `awaiting-action` | 현재 차례 플레이어의 액션 대기 |
| `need-street` | 다음 커뮤니티 카드를 열 차례 (`dealNextStreet()`) |
| `showdown` | 쇼다운 처리 필요 (`resolveShowdown()`) |
| `hand-over` | 핸드 종료 (`startHand()` 으로 다음 핸드) |

## 테스트

```bash
npm test          # 또는 node test/run-tests.js
```

핸드 평가(휠 스트레이트, 킥커 비교, 7장 중 최적 선택), 베팅 규칙(최소 레이즈,
BB 옵션, 포지션), 사이드 팟 계산, 그리고 무작위 올인 상황과 봇 100핸드
자동 플레이에서의 칩 총량 보존을 검사합니다.
