# PRD — 텍사스 홀덤 트레이너

마지막 갱신: 2026-09-17 · 상태: 1~3단계 완료

## 1. 제품 정의

> **실전 감각을 유지하는 프리미엄 포커 트레이닝.**
> 플레이할 때는 집중하게 하고, 끝나면 무엇을 고쳐야 하는지 한 문장으로 알려 주며,
> 바로 비슷한 상황을 훈련하게 만드는 제품.

핵심 흐름: **플레이 → 리뷰 → 약점 진단 → 맞춤 드릴 → 성장 확인**.
기능들은 개별 도구가 아니라 이 한 줄기로 이어져야 한다.

- 대상: 혼자 실력을 올리고 싶은 입문~중급 홀덤 플레이어
- 형태: 서버 없는 정적 웹앱 (브라우저 · PWA · 추후 TWA/Capacitor)
- 제외: 실제 돈, 광고, 소모 자원(하트 등). "제한 없이 바로 친다"가 장점이다.

## 2. 결정 사항

| 결정 | 내용 | 근거 |
|---|---|---|
| 기본 모드 | **실전** (힌트 없음, 끝나면 리뷰) | "플레이할 때는 집중" |
| 모드 종류 | 실전 / 코치 두 가지. 학습 모드는 드릴·오늘의 10문제 화면이 자동으로 맡는다 | 세 번째 설정값은 혼란만 더한다 |
| 실전 모드에서 숨기는 것 | 승률 · 필요 승률 · 아웃 · AI 판단 근거 · 생각 정리 버튼 | 답을 암시한다 |
| 실전 모드에서 남기는 것 | 핸드 족보 · 팟 · 포지션 · 액션 요약 | 보드 읽기는 힌트가 아니다 |
| 평가 단계 | 내부 4단계(좋음·무난·실수·큰 실수) 유지, 표시는 3단계(Best·Fine·Leak)로 접는다 (2단계 리뷰 재설계에서 적용) | EV 문턱과 프로파일 통계가 4단계에 묶여 있다 |
| 골드 | 지금 눌러야 할 주요 행동(새 게임 · 레이즈 · 오늘의 10문제)에만 | 의미 과부하 |
| 좌석 글자 크기 | 폰의 좌석 플레이트는 대비·크기 상향 대상에서 제외 | 9인이 들어가야 하고 사용자 요청으로 줄인 것 |
| 모바일 방향 | 세로·가로 모두 지원, 가로 강제 없음 | 세로 9인 팔각 고리 배치를 사용자가 요청함 |

## 3. 제품 구조

```
홈
 ├─ 플레이: 새 게임 · 이어하기
 └─ 교육: 오늘의 10문제 · 약점 드릴 · 무작위 드릴 · 학습 현황

플레이
 ├─ 테이블 · 액션 바
 └─ 옆 패널(Inspector): 현재 핸드 · 리뷰 · 레인지 · 세션 · 훈련

리뷰
 ├─ 핵심 누수 1개 → 타임라인 → 레인지 → 유사 상황 드릴   (2단계)

훈련
 ├─ 오늘의 10문제 · 약점 드릴(개인화) · 포지션/스트리트별 훈련 (2단계)

성장
 ├─ 플레이 스타일(4분면) · 누수 심각도 · 세션/학습 통계 분리 · 연속 학습일 (2~3단계)
```

## 4. 디자인 시스템 (요약)

- 색 의미: 골드 = 핵심 행동 / 민트 = 긍정·정답 / 코랄 = 위험·손실 / 딥 그린 = 중립 행동 / 블루그레이 = 정보
- 글자: Pretendard(내장). 본문 14px, 표·로그 12px 하한, 버튼 15px/600, 숫자는 tabular-nums
- 대비: 텍스트 4.5:1 이상. 비활성은 투명도가 아니라 색으로
- 간격: 4px 단위, 패널 반경 12px, 모달 16px, 테이블은 큰 라운드 유지
- 반응형: ≥1080 테이블+패널 나란히 · 1080 미만 서랍 · 가로 폰(≥800×≤640) 테이블 옆 도킹 · 세로 폰 서랍

## 5. 로드맵

### 1단계 — 지금 바로 (P0)
- [x] 실전 / 코치 모드 분리, 기본 실전
- [x] 색 의미 체계 정리 (골드는 CTA 에만, 의미 토큰 도입)
- [x] 로그·표·보조 텍스트 대비와 크기, tabular-nums, 폴드 좌석 표시
- [x] 옆 패널 탭 재정리: 현재 핸드 · 리뷰 · 레인지 · 세션 · 훈련, 핸드 종료 시 리뷰 탭 자동 전환
- [x] 게임 설정 기본 / 고급 분리
- [x] 모달 닫기(×) 버튼, 고정 푸터
- [x] 스타일 진단 신뢰도 문구 ("추정", 표본 기준)
- [x] 올인 확인 단계

### 2단계 — 학습 경험 강화 (P1)
- [x] 핸드 리뷰를 "핵심 누수 1개" 중심으로 (EV 손실 → 핵심 누수 · 권장 · 이유 → 레인지 보기 · 유사 상황 훈련 → 타임라인 Best/Fine/Leak, 핵심 누수만 펼침)
- [x] 약점 드릴 개인화 카드 (자리 × 가장 잦은 포지션 × 최근 20회 정확도 · 목표 문구, 홈과 학습 현황에)
- [x] 핸드 히스토리 필터(전체 · 큰 손실 · 승리 · 패배)와 자동 태그(3벳 팟 · 과콜 · 과다 폴드 · 미스 밸류), 카드마다 리뷰 · 리플레이 · 드릴 생성
- [x] 레인지 차트: 상황(오픈 · 오픈 직면 · 3벳 직면) × 상대 포지션, 4색(폴드 · 오픈/레이즈 골드 · 콜 민트 · 3벳/4벳 블루)과 혼합 비율 띠, 셀 팝오버(폴드/콜/레이즈 %)
- [x] 세션 탭 요약(핸드 수 · EV 손실 · 가장 큰 누수)과 학습 통계(최근 7일 드릴 정확도와 추이 · 연속 학습일 · 스트리트별 정확도 · 반복 실수 Top 3) 분리

### 3단계 — 완성도 (P2)
- [x] 베팅 패널 접기(폰: 레이즈를 누르면 펼침 → 확정 · 접기) + 액션 버튼 최소 높이 48px
- [x] 핸드 리플레이 미니 테이블(타원 좌석 · 보드 · 팟 · 베팅 · 폴드 · 현재 행동자) + 스트리트별 타임라인(누르면 그 시점으로) + 재생/일시정지 + 스트리트 점프 + 이 핸드로 훈련
- [x] 포지션 × 스트리트 누수 히트맵 (결정당 평균 손실, 심각도 색)
- [x] 주간 리포트(이번 주 핸드 · 결정당 손실 · 학습일, 지난 주 비교)와 목표(오늘의 10문제 · 주 3일 학습 · 연속 학습일)
- [x] 애니메이션 · 소리 옵션을 고급 설정에 (애니메이션 끄기는 카드·칩 움직임 전부)
